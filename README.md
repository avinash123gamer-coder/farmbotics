# 🌱 AGRI-BOT – Smart Farming Advisor (Front-End)

AGRI-BOT is a **front-end web application** that empowers farmers with AI-driven insights for better crop management and higher yields.  
This project is a **demo clone** of a smart farming advisor platform, rebuilt for learning and practice purposes.

---

## 🚀 Features

- **Crop Recommendation** – Get personalized crop suggestions based on soil type, climate, and season.  
- **Yield Prediction** – Estimate crop yield using simple heuristics and environmental factors.  
- **Fertilizer Suggestion** – Provides fertilizer advice based on soil pH and crop type.  
- **Price Estimation** – Calculates estimated market value for crops based on type, grade, and quantity.  
- **Plant Disease Detection (Demo)** – Upload plant images and get a placeholder analysis for common issues.  

---

## 🛠️ Tech Stack

- **HTML5, CSS3, JavaScript (Vanilla)**  
- Responsive design with basic **media queries**  
- Rule-based logic implemented on the **client-side**
